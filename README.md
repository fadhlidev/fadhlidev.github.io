# Fadhli Syaifullah — GitHub Page

A personal portfolio website for **Fadhli Syaifullah**, built as a simple static site and hosted on GitHub Pages.

## Overview

This project is a one-page portfolio site that highlights:

- Personal introduction
- Skills and technologies
- Work experience
- Selected projects
- Contact information

## Features

- Responsive single-page layout
- Smooth scrolling navigation
- Modern dark portfolio design
- SEO-friendly metadata
- Open Graph and Twitter card support
- Structured data via JSON-LD
- Lightweight static implementation

## Tech Stack

- HTML
- CSS
- JavaScript
- Google Fonts

## Project Structure

- `index.html` — Main portfolio page
- `favicon.ico` — Site icon

## Local Usage

Open `index.html` directly in a browser, or serve it with any static file server.

Example:

```bash
npx serve .
```

## Deployment

This site is designed for deployment on **GitHub Pages**.

Typical steps:

1. Push the repository to GitHub
2. Enable GitHub Pages in the repository settings
3. Select the branch containing `index.html`
4. Access the site from the GitHub Pages URL
